8. Workflow n8n mantido com credenciais e URLs existentes.

INTEGRAÇÃO SITE → N8N
- O workflow possui o webhook de site com o path: lais-imob-site-lead
- O site já envia payload compatível quando config.js estiver com useWebhook: true e webhookUrl preenchida com a URL pública completa do n8n.
- Como o pacote recebido não tinha a URL pública completa do webhook no config.js, mantive useWebhook: false para não quebrar a experiência. Nesse modo, o formulário abre o WhatsApp com a mensagem completa e natural para o atendimento.

Para ativar envio direto ao n8n:
1. Copie a URL pública do webhook no n8n.
2. Abra config.js.
3. Preencha webhookUrl.
4. Altere useWebhook para true.
