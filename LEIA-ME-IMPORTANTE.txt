CORREÇÃO COMPLETA DA HOME - v61

Este pacote contém todos os arquivos que podem interferir na página inicial.

ARQUIVOS PRINCIPAIS:
- index.html
- styles.css
- config.js
- home.js
- site.js
- atendimento.js
- imoveis-data.js

SUBSTITUA estes arquivos exatamente na pasta que o GitHub Pages está publicando.

Se depois disso a frase antiga ainda aparecer:
"Demonstração comercial: este site mostra como uma imobiliária pode captar leads com contexto"

então o problema NÃO é falta de arquivo. É um destes pontos:

1) Você está substituindo os arquivos em uma pasta diferente da publicada.
   Exemplo: enviou dentro de /noname-base, mas o GitHub Pages publica a raiz.

2) Existe outro index.html no repositório.
   No GitHub, use a busca e pesquise:
   Demonstração comercial

3) O GitHub Pages está publicando outra branch ou pasta.
   Vá em:
   Settings > Pages > Branch

4) Cache.
   Depois do commit, espere alguns minutos e abra em aba anônima ou use Ctrl + F5.

COMO CONFIRMAR SE SUBIU CERTO:
Abra o site > botão direito > Exibir código-fonte da página > Ctrl+F > pesquise:
VERSAO_PUBLICADA

Se não aparecer:
o index.html deste pacote não está sendo publicado.
