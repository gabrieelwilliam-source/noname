SITE INTELIGENTE PRO - HORIZONTE PRIME IMÓVEIS

Como subir no GitHub Pages:

1. Extraia o ZIP no computador.
2. Entre no repositório do GitHub.
3. Clique em Add file > Upload files.
4. Arraste todos os arquivos extraídos para a raiz do repositório.
5. Confirme a substituição dos arquivos antigos.
6. Clique em Commit changes.
7. Aguarde alguns minutos e atualize o site com Ctrl + F5.

Importante:
- Não suba o ZIP fechado para o GitHub.
- Suba os arquivos de dentro da pasta extraída.
- Os arquivos principais são: index.html, imovel.html, styles.css, smart-site.js, demo-data.js, home.js, site.js, property.js e as imagens .jpg.
