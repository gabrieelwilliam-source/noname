SITE CLICÁVEL - HORIZONTE PRIME

O pacote foi ajustado para manter o visual profissional e corrigir cliques em botões, cards, filtros, menu, WhatsApp e páginas individuais.

COMO SUBIR NO GITHUB:
1. Extraia este ZIP no computador.
2. No GitHub, entre no repositório do site.
3. Clique em Add file > Upload files.
4. Arraste TODOS os arquivos extraídos, não o ZIP fechado.
5. Confirme a substituição dos arquivos antigos.
6. Clique em Commit changes.
7. Aguarde alguns minutos e atualize o site com Ctrl + F5.

ARQUIVOS IMPORTANTES:
- index.html: página inicial e catálogo.
- imovel.html: página individual do imóvel.
- demo-data.js: dados dos imóveis.
- styles.css: visual e correção de cliques.
- click-fix.js: camada extra de segurança para links, filtros, cards e WhatsApp funcionarem.
- smart-site.js: recursos inteligentes como favoritos, comparação e recomendações.

IMPORTANTE:
Não envie o ZIP fechado para o GitHub Pages. Suba os arquivos extraídos.
